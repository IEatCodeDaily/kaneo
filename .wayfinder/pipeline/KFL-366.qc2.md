`0037_tiny_raza`'s own first statement on the ** ratified base commit** exactly as

outside this ticket's diff**; the implementer disclosed it honestly and escalated
for a production-reviewed remediation rather than papering over 0072 — the correct
call, and consistent with cycle-1's own "no history rewriting" ruling. Already-deployed
databases (dev, `kaneo_test`: 75 applied rows incl. 0072) are unaffected because

drizzle migrator treats it as already applied.

Probe DB dropped, instance stopped, `/tmp/qc366` removed; dev-DB scratch schema
